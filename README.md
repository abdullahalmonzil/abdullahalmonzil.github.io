# Abdullah Al Monzil — Developer Portfolio

A sleek, modern developer portfolio for **Abdullah Al Monzil**, Computer Science & Engineering Undergraduate specializing in Backend Systems & Full-Stack Development.

## 🚀 Features & Architectural Choices

- **Dark Slate Aesthetic & Glassmorphism:** Styled with a modern color palette (`#0b0f19`, `#121826`), subtle backdrop filters, and radial ambient lighting.
- **Categorized Technical Arsenal:** Organized into _Languages_, _Backend & Web_, _Databases & Systems_, and _CS Fundamentals_ without self-diminishing beginner tags.
- **Showcase of 3 Architectural Projects:**
  1. **E-Affidavit Management Platform:** Digital cryptographic verification & structured relational logging.
  2. **Single-Vendor DBMS E-Commerce:** PostgreSQL schema design, Express REST APIs, and JWT authentication.
  3. **Desktop Image Processor & Compressor:** Local multithreaded batch processing utility built in Python with Pillow & Tkinter.
- **Pure Vanilla JS:** Fast, dependency-free code handling responsive hamburger navigation, intersection-observer link highlighting, and dynamic year injection.
- **Responsive & Accessible:** Fully adaptable across mobile, tablet, and widescreen viewports with clean ARIA attributes.

## 🛠️ Local Preview & Deployment

1. **Clone or Download:**
   Clone the repository to your local machine:

   ```bash
   git clone https://github.com/abdullahalmonzil/abdullahalmonzil.github.io.git
   ```

2. **Open in Browser:**
   Open `index.html` directly in your browser, or use VS Code's **Live Server** extension:

   ```bash
   npx serve .
   ```

3. **Deploy via GitHub Pages:**
   - Push these files to your `username.github.io` repository.
   - Go to **Settings > Pages** and select the `main` branch root.
